# ICT 3131 course alignment

The course permits any full-stack technology. Crave uses React, Node/Express and SQLite; PHP, XML and XSLT are not implemented and must not be claimed in the report.

| Course principle        | Concrete implementation                                                                                                 |
| ----------------------- | ----------------------------------------------------------------------------------------------------------------------- |
| HTML5 and semantics     | HTML5 shell, language/viewport metadata; nav/main/article/section/footer; headings, real buttons and links              |
| Forms                   | Explicit labels, email/password fields, autocomplete, required/minimum constraints, client and server validation        |
| CSS fundamentals        | External stylesheet, CSS variables, class/attribute selectors, cascade, box model, spacing, typography and focus states |
| Layout                  | CSS Grid for cards/week/details; Flexbox for navigation/actions/search; mobile-first adaptations at 700/1000/1440       |
| JavaScript              | Array/object normalization, conditional rendering, functions, event handlers, checklists, async/await and errors        |
| DOM interaction         | React rendering, Intersection Observer reveal cleanup, scroll handler cleanup, native modal, clipboard and print        |
| AJAX                    | Fetch requests update recipes, auth, favorites and planner without full-page reloads                                    |
| Server-side programming | Express endpoints, middleware, validation, HTTP statuses and safe JSON errors                                           |
| Database and CRUD       | SQLite initialization, unique/foreign-key/check constraints, parameterized insert/read/upsert/delete                    |
| Authentication/security | Password hashing, server-side cookie sessions, CSRF/origin protection, ownership filtering                              |
| Responsiveness          | Flexible image ratios, card columns and mobile navigation; browser tests configured for 375/768/1440 px                 |
| Accessibility           | Skip link, semantics, visible keyboard focus, status/alert feedback, reduced motion, labelled modal and image fallbacks |
| Testing                 | Node/Supertest integration, Vitest/Testing Library interactions, Playwright browser workflows                           |

Implementation measures do not establish formal accessibility conformance or performance scores. Report actual executed checks from TESTING.md, not assumptions based on the presence of test scripts.
